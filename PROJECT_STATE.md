# Project state

Reusable local Feishu Todo-agent source with personal chat tasks and the optional
team project-tree webpage. See README for installation, languages and limitations,
`docs/DESIGN_LANGUAGES.md` for locale boundaries and `docs/TEAM_WEB_SETUP.md` for
deployment examples. No production address, credentials or live verification is
part of this delivery. Fixtures remain in `tests/`, `web/tests/` and `demo/`.
